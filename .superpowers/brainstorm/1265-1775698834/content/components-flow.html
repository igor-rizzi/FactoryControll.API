Componentes de UI e Fluxo de Dados

Como as páginas são construídas e como os dados fluem da API para a tela

🧩 Componentes de Layout (compartilhados)
Sidebar
Colapsável, menu por role, item ativo destacado, logo FC
Topbar
Breadcrumb, ThemeToggle (🌓), avatar + dropdown com logout
DataTable
Tabela genérica com paginação, busca e ações por linha
PageHeader
Título + subtítulo + botão de ação primária (ex: "Novo")
🔄 Fluxo de Dados (por página de listagem)
Page.tsx
Server ou Client component
→
useQuery()
TanStack Query
→
service.listar()
lib/api/[módulo].service.ts
→
axios.get()
+ Bearer token auto
→
FactoryControll.API
GET /api/[endpoint]/listar
Para mutations (criar/editar/deletar): useMutation() → service.inserir() → queryClient.invalidateQueries() para recarregar a lista automaticamente.
📄 Padrão de cada módulo CRUD
Listagem /[módulo]
  • PageHeader + botão "Novo"
  • DataTable paginada
  • Ações: Editar | Deletar
  • Toast de confirmação
Formulário /novo e /[id]
  • shadcn Form + react-hook-form
  • Validação no cliente (zod)
  • Estado loading no submit
  • Redirect após sucesso
Reembolsos (especial)
  • Upload de comprovante
  • Badge de status colorido
  • Ações Aprovar/Reprovar (role)
  • Preview do arquivo anexado
⚠️ Tratamento de erros e estados
⏳
Loading
Skeleton em tabelas e cards
❌
Erro API
Toast de erro com mensagem da API
🚫
Sem permissão
Redirect 403 → /unauthorized
✅
Sucesso
Toast verde + invalidate query
