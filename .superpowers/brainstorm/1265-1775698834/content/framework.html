Qual framework React usar?

Você pediu React sem Vite — qual dessas abordagens se encaixa melhor no projeto?

A

Next.js (App Router)

Framework React full-stack com SSR, SSG e rotas baseadas em arquivos. Ecossistema maduro, excelente DX, suporte nativo a JWT via middleware. É o padrão da indústria para SPAs + SSR hoje.

  • ✅ Roteamento por arquivos (sem config manual)
  • ✅ Middleware nativo para auth JWT
  • ✅ Build com Turbopack (não usa Vite)
  • ✅ Grande comunidade e docs extensas
  • ⚠️ Mais opinionado — estrutura define o projeto
B

Remix

Framework React focado em web standards (fetch API, form actions). SSR por padrão, progressive enhancement nativo. Usa esbuild/Express internamente, não Vite por padrão.

  • ✅ Filosofia de web standards (formulários nativos)
  • ✅ Loaders/Actions elegantes para data fetching
  • ✅ Ótimo para apps com muitos formulários
  • ⚠️ Comunidade menor que Next.js
  • ⚠️ Curva de aprendizado diferente
C

React + Webpack (SPA puro)

Configuração manual com webpack + babel. SPA clássico sem SSR. Total controle sobre o tooling.

  • ✅ Controle total da configuração
  • ✅ SPA simples, sem complexidade de servidor
  • ⚠️ Configuração manual e trabalhosa
  • ⚠️ CRA oficialmente abandonado pelo Meta
  • ⚠️ Build mais lento que alternativas modernas
