Qual biblioteca de UI?

Escolha o design system e componentes que usaremos no frontend

A

Tailwind CSS + shadcn/ui

Componentes headless copiados direto para o projeto (não é uma dependência — você possui o código). Visual moderno e limpo, altamente customizável.

  • ✅ Componentes no seu código (sem lock-in)
  • ✅ Visual profissional e moderno out-of-the-box
  • ✅ Integração oficial com Next.js
  • ✅ Tailwind = sem CSS externo, tudo inline
  • ⚠️ Requer familiaridade com Tailwind
B

Material UI (MUI v6)

Biblioteca completa baseada no Google Material Design. Componentes prontos para tudo: tabelas, formulários, dialogs, etc. Visual familiar e empresarial.

  • ✅ Componentes muito completos (DataGrid, etc.)
  • ✅ Temas e customização via sistema próprio
  • ✅ Muito usado em sistemas internos/corporativos
  • ⚠️ Bundle maior
  • ⚠️ Visual "genérico" se não customizado
C

Ant Design (antd v5)

Design system enterprise-grade da Alibaba. Extremamente completo, focado em sistemas de gestão (exatamente o caso do FactoryControll).

  • ✅ Ideal para sistemas de gestão/ERP
  • ✅ Tabelas, formulários, layouts prontos
  • ✅ ProComponents (ProTable, ProForm) para CRUD rápido
  • ⚠️ Visual mais "enterprise", menos moderno
  • ⚠️ Bundle grande
